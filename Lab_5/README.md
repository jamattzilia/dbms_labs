# Laboratory Work No. 5

**Subject:** Creation of presentations.

**Purpose:**
- study the principles of creating a slide show by means of Microsoft PowerPoint, including animation and voice accompaniment;
- acquire skills of presenting a lecture on the basis of a slide show.

**Variant:** this laboratory work has no variants and no fixed dataset — the assignment is a set of PowerPoint techniques to practice on a presentation of the student's own choosing. The demo deck below ([`DBMS_Labs_Overview.pptx`](DBMS_Labs_Overview.pptx)) summarizes Labs 1–4 of this same course, so that building it also required applying nearly every technique in the list.

## Recommendations on planning slides (from the assignment)

1. A presentation is a set of slides supporting a talk. Keep all four aims in mind — inform, entertain, create emotional impact, prompt action — but an educational presentation exists mainly to show command of the subject, its depth, and the results of one's own work.
2. Structure must be easy to remember: aim for no more than three key points per slide (seven at the absolute maximum).
3. Start from simple, general concepts and move toward the more specific and difficult.
4. Common structuring methods: chronological, sequential, geographical, categorical, comparison/contrast of extremes, hierarchical, radius-expanding.
5. Use exactly two fonts on a slide — one for headers, one for body text.
6. Mix upper and lower case normally; reserve all-caps for emphasis only.
7. Keep consistent line spacing.
8. Keep one consistent header/subheading style throughout. Slides should be simple, tasteful, and above all easy to read.
9. Do not mix more than three colors on a slide.
10. Visual aids (illustrations, diagrams, tables, charts) communicate faster than words, explain difficult concepts more easily, and hold the audience's attention — images should be large and legible from a distance.
11. Every table and chart needs a caption.
12. Use animation and transitions to underline specific points, not to show off special effects.
13. Any sound used during transitions or animation should draw attention back to the slide content, not call attention to itself.
14. Rehearse the timing of the talk with PowerPoint's own tools before presenting, and use the rehearsal to also check how the slides read.

## PowerPoint 2007 — actions covered

| Action | Menu path |
|---|---|
| Create an empty presentation | File ▸ New ▸ Blank and recent ▸ Create |
| Create from a template / theme | File ▸ New ▸ Templates / Themes |
| Add a new slide | Home ▸ Slides ▸ New Slide |
| Change a slide's layout | Home ▸ Slides ▸ Layout (Title; Title and Content; Two Content; Picture with Caption; Title Only; Blank) |
| Apply a design theme | Design ▸ Themes |
| Change the slide background | Design ▸ Background ▸ Background Styles |
| Insert a text box / WordArt / symbol | Insert ▸ Text |
| Insert a table | Insert ▸ Table |
| Paste an Excel table as a linked object | Home ▸ Clipboard ▸ Paste ▸ Paste Special ▸ Paste link |
| Insert an Excel chart | Insert ▸ Illustrations ▸ Chart |
| Insert a picture / clip art / SmartArt | Insert ▸ Illustrations |
| Insert an embedded Office object | Insert ▸ Text ▸ Object |
| Configure animation on an object | Animations ▸ Animation ▸ Custom Animation ▸ Add Effect |
| Reorder slides | View ▸ Presentation Views ▸ Slide Sorter (drag and drop) |
| Configure the slide show | Slide Show ▸ Set Up ▸ Set Up Slide Show |
| Rehearse and record slide timings | Slide Show ▸ Set Up ▸ Rehearse Timings |
| Save as a self-running show | Office button ▸ Save As ▸ PowerPoint Show |
| Mixed slide orientation | build two separate presentations (one portrait, one landscape) and hyperlink between them — PowerPoint applies one orientation per file |
| Package for CD | Office button ▸ Publish ▸ Package for CD |

## Demo deck: *DBMS Labs Overview*

To put the technique list into practice, the demo presentation summarizes this course's own Labs 1–4 (number systems, MS-DOS, HTML, relational databases) — genuinely "reporting the results of one's own work," which the assignment names as the main purpose of an educational presentation.

| # | Slide | Layout / technique demonstrated |
|---|---|---|
| 1 | Title | Title slide layout, dark background, two-font theme |
| 2 | Agenda | Title-and-content, numbered list capped at 4 points |
| 3 | Lab 1 — Number Systems | Title-and-content with a stat callout (the variant 6 results) |
| 4 | Lab 2 — MS-DOS Files & Directories | Two-content layout: directory tree + command highlights |
| 5 | Lab 3 — HTML | Picture-with-caption layout, screenshot of a rendered page |
| 6 | Lab 4 — Relational Databases (data) | Table slide, captioned, built from the real Student data |
| 7 | Lab 4 — Relational Databases (chart) | Native chart slide (specialty distribution), captioned |
| 8 | Conclusion | Title-and-content closing slide |

Design choices made in line with the assignment's own recommendations: a single two-color "Midnight Executive" palette (navy / ice blue / white) used throughout (recommendation 9), one heading font and one body font (recommendation 5), no more than four bullet points on any slide (recommendation 2), and both the table and the chart carry their own caption (recommendation 11).

### Notes on what could not be produced in this environment

PowerPoint itself is not available here, so the deck was built directly as a `.pptx` file (via a structured, theme-driven generator) rather than clicked together in the PowerPoint 2007 UI shown in the assignment's screenshots. Two PowerPoint-only features are consequently described rather than demonstrated live: **Rehearse Timings** (recorded per-slide timing data that only exists inside a live PowerPoint session) and **voice accompaniment** (a narration track). Everything else in the technique table — slide layouts, theme/background, table, native chart, picture with caption, and the structural recommendations — is present in the delivered file and was verified by rendering every slide to an image.

## Conclusion

This laboratory work covered the principles of planning a readable, well-structured slide show and the concrete PowerPoint 2007 actions needed to build one: creating a presentation from scratch, a template, or a theme; adding and laying out slides; applying a design theme and background; inserting text, tables, Excel-linked data, native charts, pictures and embedded objects; configuring animation; sorting slides; and configuring and saving a slide show. These techniques were applied directly in `DBMS_Labs_Overview.pptx`, a presentation of the course's own Labs 1–4.
