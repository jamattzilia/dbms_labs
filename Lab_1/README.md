# Лабораторная работа №1

**Тема:** Системы счисления. Перевод чисел из одной системы счисления в другую. Арифметика в системах счисления.

**Цель работы:** приобрести навыки выполнения операций в различных системах счисления.

**Вариант: 6**

## Задание

Заполнить таблицу, переведя каждое из четырёх заданных чисел в остальные системы счисления:

| № | Десятичное число | Двоичное число | Восьмеричное число | Шестнадцатеричное число |
|---|---|---|---|---|
| 1 | 654.27 | | | |
| 2 | | 1100001010101 | | |
| 3 | | | 632 | |
| 4 | | | | 5AD |

## Решение

### 1. Число 654.27(10)

**Перевод целой части (654) в двоичную систему — метод деления на основание:**

| Деление | Частное | Остаток |
|---|---|---|
| 654 : 2 | 327 | 0 |
| 327 : 2 | 163 | 1 |
| 163 : 2 | 81 | 1 |
| 81 : 2 | 40 | 1 |
| 40 : 2 | 20 | 0 |
| 20 : 2 | 10 | 0 |
| 10 : 2 | 5 | 0 |
| 5 : 2 | 2 | 1 |
| 2 : 2 | 1 | 0 |
| 1 : 2 | 0 | 1 |

Считывая остатки снизу вверх: **654(10) = 1010001110(2)**

**Перевод дробной части (0.27) в двоичную систему — метод умножения на основание:**

| Умножение | Результат | Цифра |
|---|---|---|
| 0.27 × 2 | 0.54 | 0 |
| 0.54 × 2 | 1.08 | 1 |
| 0.08 × 2 | 0.16 | 0 |
| 0.16 × 2 | 0.32 | 0 |
| 0.32 × 2 | 0.64 | 0 |
| 0.64 × 2 | 1.28 | 1 |
| 0.28 × 2 | 0.56 | 0 |
| 0.56 × 2 | 1.12 | 1 |
| 0.12 × 2 | 0.24 | 0 |
| 0.24 × 2 | 0.48 | 0 |

**0.27(10) ≈ 0.0100010100(2)**

Итого: **654.27(10) = 1010001110.0100010100(2)**

**Перевод в восьмеричную систему** (аналогично, деление/умножение на 8):

654 : 8 = 81, ост. 6; 81 : 8 = 10, ост. 1; 10 : 8 = 1, ост. 2; 1 : 8 = 0, ост. 1 → **654(10) = 1216(8)**

0.27×8=2.16→2; 0.16×8=1.28→1; 0.28×8=2.24→2; 0.24×8=1.92→1 → **0.27(10) ≈ 0.2121(8)**

**654.27(10) = 1216.2121(8)**

**Перевод в шестнадцатеричную систему** (деление/умножение на 16):

654 : 16 = 40, ост. 14(E); 40 : 16 = 2, ост. 8; 2 : 16 = 0, ост. 2 → **654(10) = 28E(16)**

0.27×16=4.32→4; 0.32×16=5.12→5; 0.12×16=1.92→1; 0.92×16=14.72→E → **0.27(10) ≈ 0.451E(16)**

**654.27(10) = 28E.451E(16)**

### 2. Число 1100001010101(2)

**Перевод в десятичную систему** (суммирование по разрядам):

1100001010101(2) = 1·2¹²+1·2¹¹+0·2¹⁰+0·2⁹+0·2⁸+0·2⁷+1·2⁶+0·2⁵+1·2⁴+0·2³+1·2²+0·2¹+1·2⁰
= 4096+2048+64+16+4+1 = **6229(10)**

**Перевод в восьмеричную систему** (группировка по 3 бита справа налево, с дополнением нулями слева):

001 100 001 010 101 → 1 4 1 2 5 → **14125(8)**

Проверка: 1·8⁴+4·8³+1·8²+2·8+5 = 4096+2048+64+16+5 = 6229 ✓

**Перевод в шестнадцатеричную систему** (группировка по 4 бита справа налево):

0001 1000 0101 0101 → 1 8 5 5 → **1855(16)**

Проверка: 1·16³+8·16²+5·16+5 = 4096+2048+80+5 = 6229 ✓

### 3. Число 632(8)

**Перевод в десятичную систему:**

632(8) = 6·8² + 3·8¹ + 2·8⁰ = 384 + 24 + 2 = **410(10)**

**Перевод в двоичную систему** (каждая восьмеричная цифра → 3 бита):

6 = 110, 3 = 011, 2 = 010 → **110011010(2)**

Проверка: 1·256+1·128+0+0+1·16+1·8+0+1·2+0 = 256+128+16+8+2 = 410 ✓

**Перевод в шестнадцатеричную систему** (группировка двоичного кода по 4 бита):

0001 1001 1010 → 1 9 A → **19A(16)**

Проверка: 1·256+9·16+10 = 256+144+10 = 410 ✓

### 4. Число 5AD(16)

**Перевод в десятичную систему:**

5AD(16) = 5·16² + 10·16¹ + 13·16⁰ = 1280 + 160 + 13 = **1453(10)**

**Перевод в двоичную систему** (каждая шестнадцатеричная цифра → 4 бита):

5 = 0101, A = 1010, D = 1101 → 0101 1010 1101 → **10110101101(2)** (без ведущего нуля)

Проверка: 1024+256+128+32+8+4+1 = 1453 ✓

**Перевод в восьмеричную систему** (группировка двоичного кода по 3 бита):

010 110 101 101 → 2 6 5 5 → **2655(8)**

Проверка: 2·512+6·64+5·8+5 = 1024+384+40+5 = 1453 ✓
