# Лабораторная работа №2

**Тема:** Определение свойств операционной системы. Работа с файлами и каталогами.

**Цель работы:** приобретение основных навыков работы в среде операционной системы MS-DOS.

**Вариант: 6**

## Краткие теоретические сведения

Операционная система (ОС) обеспечивает интерфейс пользователя и прикладных программ с устройствами компьютера, принимает команды и исполняет их. MS-DOS (MicroSoft Disk Operating System) состоит из BIOS, файлов `io.sys` и `msdos.sys`, командного процессора `command.com`, а также драйверов и файлов `config.sys` / `autoexec.bat`.

### Используемые команды MS-DOS

**Служебные команды**

| Команда | Назначение |
|---|---|
| `VER` | вывод версии MS-DOS |
| `CLS` | очистка экрана |
| `DATE` | запрос текущей даты |
| `TIME` | запрос текущего времени |

**Навигация по дискам и каталогам**

| Команда | Назначение |
|---|---|
| `ИмяДиска:` | смена текущего диска (например, `D:`) |
| `CD ИмяКаталога` | переход в указанный каталог |
| `CD ..` | переход в родительский каталог |
| `CD \` | переход в корневой каталог текущего диска |

**Работа с файлами**

| Команда | Назначение |
|---|---|
| `REN СтароеИмя НовоеИмя` | переименование файла |
| `TYPE ИмяФайла` | просмотр содержимого файла |
| `EDIT ИмяФайла` | редактирование файла |
| `COPY ФайлОригинал ФайлКопия` | копирование файла |
| `COPY ИмяФайла PRN` | вывод файла на печать |
| `MOVE ИмяФайла МаршрутКаталога` | перемещение файла |
| `DEL ИмяФайла` | удаление файла |
| `COPY CON ИмяФайла` (ввод текста, завершение `F6`/`Ctrl+Z`) | создание нового текстового файла с клавиатуры |

**Работа с каталогами**

| Команда | Назначение |
|---|---|
| `DIR [МаршрутКаталога] [/P]` | просмотр содержимого каталога (`/P` — постранично) |
| `MD ИмяКаталога` | создание нового каталога |
| `MOVE СтароеИмя НовоеИмя` | переименование каталога |
| `RD ИмяКаталога` | удаление пустого каталога (нельзя удалить текущий, нужно сначала перейти в родительский) |

## Задание (Вариант 6)

Создать в каталоге `STUDENT` следующую иерархическую файловую систему:

```
C:\STUDENT
├── D1 (d1.txt)
│   └── D2 (d2.txt)
│       ├── D3 (d3.txt)
│       ├── D4 (d4.txt)
│       └── D5 (d5.txt)
└── D6 (d6.txt)
    └── D7 (d7.txt)
        └── D8 (d8.txt)
```

Каталоги `D1` и `D6` — два самостоятельных подкаталога `STUDENT`. Внутри `D1` находится только `D2`, а в нём — `D3`, `D4`, `D5`. Ветка `D6` — это цепочка вложенных каталогов: `D6` → `D7` → `D8` (каждый следующий каталог вложен в предыдущий, а не является его «соседом»).

Каждый каталог `D1`–`D8` содержит одноимённый текстовый файл (`d1.txt`–`d8.txt`).

## Решение — последовательность команд MS-DOS

```dos
C:\>MD STUDENT
C:\>CD STUDENT

C:\STUDENT>MD D1
C:\STUDENT>CD D1
C:\STUDENT\D1>COPY CON d1.txt
Файл каталога D1
^Z

C:\STUDENT\D1>MD D2
C:\STUDENT\D1>CD D2
C:\STUDENT\D1\D2>COPY CON d2.txt
Файл каталога D2
^Z

C:\STUDENT\D1\D2>MD D3
C:\STUDENT\D1\D2>CD D3
C:\STUDENT\D1\D2\D3>COPY CON d3.txt

^Z
C:\STUDENT\D1\D2\D3>CD ..

C:\STUDENT\D1\D2>MD D4
C:\STUDENT\D1\D2>CD D4

Файл каталога D4
^Z
C:\STUDENT\D1\D2\D4>CD ..

C:\STUDENT\D1\D2>MD D5
C:\STUDENT\D1\D2>CD D5
C:\STUDENT\D1\D2\D5>COPY CON d5.txt
Файл каталога D5
^Z
C:\STUDENT\D1\D2\D5>CD ..
C:\STUDENT\D1\D2>CD ..
C:\STUDENT\D1>CD ..

C:\STUDENT>MD D6
C:\STUDENT>CD D6

^Z

C:\STUDENT\D6>MD D7
C:\STUDENT\D6>CD D7

^Z

C:\STUDENT\D6\D7\D8>COPY CON d8.txt
Файл каталога D8
^Z

C:\STUDENT\D6\D7\D8>CD \
C:\>
```

### Проверка результата

Для проверки построенной структуры используется команда постраничного просмотра дерева каталогов:

```dos
C:\>CD STUDENT
C:\STUDENT>DIR /S /P
```

Команда `DIR /S` рекурсивно выводит содержимое каталога `STUDENT` и всех вложенных в него подкаталогов `D1`–`D8`, позволяя убедиться, что структура и файлы (`d1.txt`–`d8.txt`) созданы согласно заданному варианту.
